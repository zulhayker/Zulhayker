# Cara Pakai

1. Buat repository GitHub bernama tepat: `zulhayker`
2. Pastikan repository milik akun `zulhayker`, sehingga path profil menjadi `zulhayker/zulhayker`.
3. Upload seluruh isi folder ini ke root repository.
4. Pastikan branch utama bernama `main`.
5. Buka tab **Actions** lalu jalankan workflow **Generate Contribution Snake** satu kali.
6. Setelah workflow selesai, branch `output` akan dibuat otomatis dan animasi contribution snake akan tampil di README.
