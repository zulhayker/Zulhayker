# Assets

README utama saat ini memakai layanan gambar/SVG/GIF eksternal agar langsung berfungsi tanpa file tambahan.

Jika nanti ingin emoji GIF lokal benar-benar bergerak, taruh file berikut di folder ini:

- `wave.gif`
- `fire.gif`
- `rocket.gif`
- `sparkle.gif`
- `coding.gif`

Contoh penggunaan:

```html
<img src="./assets/wave.gif" width="40" alt="Wave">
<img src="./assets/fire.gif" width="32" alt="Fire">
<img src="./assets/rocket.gif" width="32" alt="Rocket">
```
